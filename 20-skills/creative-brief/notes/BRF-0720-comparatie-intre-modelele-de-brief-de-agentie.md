# Modelele de brief de agenție au același nucleu, dar fiecare optimizează altceva — inspirația, concizia, contextul, procesul sau dovada

> **Ideea în o frază:** sub formulare diferite, toate brief-urile întreabă cine, ce schimbare, ce mesaj unic și ce dovadă; diferă prin ce adaugă în jur.

## Explicație

Comparat cu cele șase componente McTigue–Rucker ([[BRF-0702]]), setul arată așa (✓ = rubrică explicită, ~ = implicit sau parțial, — = lipsește):

| Componentă | Euro RSCG | Get/To/By | Naked | Red Cell | Singleton O&M |
|---|---|---|---|---|---|
| Obiectiv / rol | ✓ (de business) | ~ (TO) | ✓ (problemă de business) | ✓ | ✓ (rol) |
| Răspunsul dorit | ~ | ✓ | ✓ (efect dorit) | ✓ | ✓ (gândește/simte/fă) |
| Țintă | ✓ | ✓ | ✓ (imagine „bogată") | ✓ | ~ (publicul, în insight) |
| Insight | ✓✓✓ (consumator, brand, categorie) | — | ~ („sau cereți-ne") | — | ✓ (util) |
| Mesaj unic | ✓ (gând unic) | ✓ (BY) | ✓ | ✓ (propunere) | ✓ (cel mai important punct) |
| Dovadă / RTB | ~ (de ce le-ar păsa) | ✓ (BECAUSE) | — | ✓ (suport + beneficiu final) | ✓ (emoțională, senzorială, rațională) |
| Personalitate / ton | ✓ | — | — | ✓ (tonalitate) | ✓ (selectiv) |
| Obligatorii | ✓ | — | — | ✓ | ✓ |
| Măsurare | ✓ | — | ✓✓ (hard, soft, buzz) | — | — |
| Proces / aprobări | ✓ (4 trepte) | — | ~ | ✓✓ (calendar, 5 semnături) | ✓ (semnătura clientului) |
| Context / istoric | — | — | ✓✓ | — | — |

**Ce optimizează fiecare:**

- **Euro RSCG** — profunzimea insight-ului (triangulare) și filtrul intern înaintea clientului.
- **Get/To/By** — concizia și schimbarea de comportament; e un test de claritate.
- **Naked** — contextul și învățarea; cea mai bogată evaluare.
- **Red Cell** — procesul și responsabilitatea; scara propunere → suport → beneficiu final.
- **Singleton O&M** — credibilitatea: punctul unic e legat de o dovadă, inclusiv senzorială.

**Ce lipsește tuturor:** cadrul de referință competitiv explicit, pe care McTigue și Rucker îl consideră adesea neglijat, deși e esențial. Doar Euro RSCG și Naked au măsurare, componenta pe care autorii o cer în orice brief.

## Aplicare

- Alege formularul după problemă: brief rapid de social → Get/To/By; relansare de brand cu istoric lung → Naked; producție mare cu mulți aprobatori → Red Cell; categorie-paritate unde dovada decide → Singleton O&M.
- Indiferent de formular, adaugă pe margine cadrul de referință și indicatorul de măsurare.
- Exercițiu: completează același caz în două formulare și discută ce a scos la iveală fiecare.
